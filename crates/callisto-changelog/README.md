# callisto-changelog

Package CHANGELOG.md generator and section extractor for Callisto.

## Overview

`callisto-changelog` manages package-level `CHANGELOG.md` file generation and updating:

- Extracting previous release entries from existing markdown changelogs.
- Formatting release headings, commit lists, and author metadata.
- Preserving CRLF and UTF-8 line endings on updates.
