2. Key Technical Concepts:

- **Callisto**: Rust CLI + moon WASM extension for polyglot monorepo versioning, byte-compatible with `@changesets/cli` file format
- **Cargo workspace**: 10 crates in strict architectural layers (Layer 1: model/format MIT/Apache-2.0; Layer 1.5: vcs MIT/Apache-2.0; Layer 2: manifests/conventional/changelog AGPL; Layer 3: graph AGPL; Layer 4: cli/moon AGPL; Dev: fixtures AGPL)
- **ApplyPermit**: Zero-sized capability token — `granted_unless_dry_run(bool) -> Option<Self>` — makes forgetting `--dry-run` a compile error. `force_for_tests()` gated by `#[cfg(any(test, feature = "test-util"))]`
- **manifest_cache**: `open_cached()` memoizes read-only manifest opens by path within a `Workspace` lifetime. Write-open path in `apply.rs` always calls `callisto_manifests::open` directly to avoid aliasing.
- **GitDataSource trait**: Consolidates 5 hand-rolled gix/shell patterns. `GitRepository` (native gix) and `ShellGit` backends. `GitAccess::discover` with asymmetric fallback: reads retry through shell on native error; writes never retry through shell.
- **TagIndex**: Built lazily via `OnceCell` on first `ws.tags()` call.
- **PublishOrchestrator**: Native-tool pipeline — `cargo publish` for crates.io, `npm publish` for npm, `twine upload --skip-existing` for PyPI. No HTTP client.
- **moon v2.4.6 PDK types**: `RegisterExtensionInput {id: Id}`, `RegisterExtensionOutput {name, description: Option<String>, plugin_version}`, `ExecuteExtensionInput {args, context: MoonContext}`
- **PEP 508 round_trip**: Rewrites `==X.Y.Z` → `==NEW`, `~=X.Y.Z` → `~=NEW`, `>=X.Y.Z` → `>=NEW`, `>=X.Y.Z,<A.B` → `>=NEW,<NEXT_MAJOR`. Returns `None` for 3+ clause or unrecognized forms.
- **PackageId::matches()**: Bare acts as ecosystem wildcard ("could be same package"). `resolve_target_package` handles multi-match by returning `Err(AmbiguousName)` on 2+.
- **serial_test**: Added to manifest_cache tests to prevent global `OPEN_CALL_COUNT` contamination from parallel test runs.
