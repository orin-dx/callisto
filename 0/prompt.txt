Medium severity:
- E. Git probes: GitAccess treats any non-zero exit as "absent". list_tags matches the English text "not a git repository" in stderr, and a shallow clone looks like zero tags.
- F. .exists() as an absence check:
  - Wrong decisions: a missing pre.json, callisto.toml, changelog, or init guard file can be misread, so a bump goes stable instead of pre-release, config falls back to defaults, or an existing file is overwritten.
  - Lost history: a changelog the code believes is absent is replaced, which drops its history.
- G. Atomic write and runner: directory-sync errors are dropped after the rename. The process runner can return exit 0 with empty stdout when a reader thread times out.
- H. Fallbacks: the release-notes fallback, a GitHub release body missing draft, and a changeset slug collision that silently overwrites a pending changeset.
