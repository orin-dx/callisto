**1 (critical) — the changelog read path ignores `Package.changelog`.** The spec mandates deriving `{pkg_dir}/CHANGELOG.md` from `pkg.manifests.first().path.parent()`. But `Package.changelog: Option&lt;PathBuf&gt;` (`package.rs:17`) is the already-resolved changelog path, always `Some`, and user-overridable — `walk.rs:388-392` sets it to `rel_path.join(override_path)` when a `[[package]]` rule specifies `changelog = "..."`. It is exactly what the **write** side uses (`version.rs:148`). The override is a supported, tested feature: `per_package_config_test.rs:63-99` asserts a configured package resolves to `RELEASES.md`, explicitly not `CHANGELOG.md`.
