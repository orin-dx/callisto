---

Callisto tracks pending changes per package with changeset files, computes version bumps across a dependency graph (with cascade rules for dependents), rewrites manifests in place preserving formatting, and releases each package once its version is unreleased: registry publish, git tag, GitHub release.

TOML edits preserve concrete syntax through `toml_edit`; JSON edits preserve key order, detected indentation and line endings, but normalize arbitrary hand-formatted layout. Disk writes are atomic (`NamedTempFile` + `fs::rename`). All Git access runs through the system `git` binary. `unsafe_code = "forbid"` workspace-wide.
