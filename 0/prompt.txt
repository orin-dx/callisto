One thing to have ready before you start. If the run gets past asset upload and then fails, a recovery dispatch rebuilds the assets, and tar -czf isn't byte-reproducible, so observe_artifact_upload reads the uploaded asset as ArtifactAssetDiffers and aborts with ReleaseRecoveryUnresolved. The unblock needs no code change: delete the mismatched assets from the release, then re-dispatch — with no asset of that name, observe returns Absent and the upload op runs normally. Don't reach for the "obvious" reproducible-tar fix; the GNU flags fail on the macOS leg, which I tested.
