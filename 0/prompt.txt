  ## 6. What canonical-only changes for a user with unambiguous names
  
  - `ReleasePackageId` (`eco/native-name`, one per manifest, stable under promotion) already is the canonical distribution id, in every release wire. `Package::key()` (directory) already is the stable owner key.
  - What changes for an unambiguous user:
    - Written forms flip from `foo` to `cargo/foo` in `add`, pre.json, status/version JSON and matrix keys.
    - Default tag namespace flips from `foo@x` to `cargo/foo@x`. This is the Tag-migration risk: tags are not renamed, so a changed display id means the next release looks for different tags unless a deterministic template is pinned.
