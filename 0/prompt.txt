2. Key Technical Concepts:

- **Callisto**: Rust CLI + Moon WASM extension for polyglot monorepo versioning (10 crates)
- **ResolvedConfig**: Config struct built from `callisto.toml`; has `packages: Vec<(PackageId, PackageConfig)>` for `[[package]]` overrides; missing `package_sets` for `[[package-set]]`
- **ManifestWalkResolver::build**: Builds the workspace graph; applies `pkg_override` from `cfg.packages` to each package; never falls back to `cfg.package_sets`
- **`[[package-set]]` semantics**: Bulk config-override mechanism (NOT version synchronization). Same fields as `[[package]]` but applies to ALL matching packages. Priority: `[[package]]` > `[[package-set]]`. (Derived from Changesets/Knope research.)
- **Changesets `linked` vs `fixed`**: `linked` = only packages already releasing get unified, non-releasing NOT pulled in. `fixed` = ALL members pulled in even without changesets. The `applyLinks` function in `packages/assemble-release-plan/src/apply-links.ts` implements this.
- **Crash-safe apply**: Both Changesets and Knope write manifests BEFORE deleting changesets; neither writes a lock/plan file; neither is idempotent. Correct fix for Callisto: use `PlannedBump.from`/`PlannedBump.to` to check current manifest version before writing.
- **PlannedBump**: Has `from: Version` and `to: Version` — sufficient for idempotency guard
- **Version::compare()**: Returns `Result<Ordering, GrammarMismatch>`; use this NOT `==` (derived PartialEq compares raw strings, "1.0" != "1.0.0")
- **parse_publish_target()**: New function mapping strings ("crates-io", "npm", "pypi", "none", etc.) to `PublishTarget` enum values
- **`#[serde(deny_unknown_fields)]`**: Added to all `callisto.toml`-parsing Raw* structs (NOT to RawMoon* structs which parse moon.yml)
- **BTreeMap::insert return value**: Returns `Some(old)` on collision — used to detect duplicate PackageId
- **Conservative round_trip policy**: Compound Cargo ranges with `<`/`<=` upper bounds now return `None` rather than producing impossible constraints
