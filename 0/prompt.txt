Transferable patterns:

- Adopt a single fixed release group and one canonical tag. Nx proves the useful mechanics: fixed membership means no subset release, one tag per coordinated release, and custom tag patterns can express `callisto@X.Y.Z`.
- Adopt manifest/plan-derived recovery: Changesets’ “unpublished plan” and Nx’s explicit registry lookup before re-publishing are the strongest directly relevant ideas. - Separate preparation/review from execution as Release Please does, but bind execution to the immutable reviewed PR commit/plan. Release Please’s explicit non-transactionality demonstrates why rerun logic must be intentional.
- Use Knope’s draft-release → upload-all-assets → publish ordering for public GitHub visibility, but add post-upload checksum and attestation verification before declaring completion.
- Preserve dry-run previews, but reject treating them as rehearsal evidence. None of the four provides the requirement’s isolated end-to-end interruption/fresh-runner recovery exercise.
