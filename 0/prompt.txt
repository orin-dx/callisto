## Summary

**Bug fixed**: `crates/callisto-graph/src/changed.rs`, `changed_since_last_tag` — it called `git.commits_since(Some(&amp;qualified), &amp;[])` with an empty pathspec, walking the whole repo's commit history since the package's tag instead of just that package's paths. Any commit anywhere in the workspace short-circuited `Ok(true)` for every package, making the path-scoped `git diff --quiet` check (and the `status` command's `changed_since_last_tag` field) effectively meaningless in an active monorepo.

**Fix**: moved the existing `package_paths(pkg)` computation above the `commits_since` call and passed it in place of `&amp;[]`, scoping the short-circuit identically to the `git diff --quiet` fallback below. Polarity preserved: a non-empty scoped `commits_since` result still returns `Ok(true)`; an empty scoped result still falls through to the `git diff --quiet` check (which alone catches uncommitted working-tree changes).

**Regression test** (`other_package_unchanged_when_only_sibling_package_has_commits_since_tag` in the same file): sets up two packages, `pkg-a` and `pkg-b`, each with its own tag. Confirmed this test **fails** on the pre-fix code (`pkg-b` wrongly reports `changed: true`) and **passes** after the fix (`pkg-b` reports `false` and the scoped `git diff --quiet` fallback runs, scoped to `pkg-b`'s own path).
