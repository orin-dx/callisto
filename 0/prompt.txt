| Verify semantic inputs only within Callisto | A versioned, deterministic domain digest transcript—not a serialization accident. |
| Allow arbitrary external tooling to independently reproduce a semantic digest | JCS/RFC 8785, or an explicitly specified length-prefixed binary transcript with test vectors. |

My default recommendation is the middle path: raw-byte SHA-256 for transport plus a versioned, domain-specific digest transcript for semantic inputs. It is simpler, avoids coupling security to JSON serialization details, and can still become cross-language if its byte layout and test vectors are specified.

Use JCS only if the requirement explicitly says that external systems need to produce or verify the digest from JSON. Do not use `olpc-cjson` for a public JSON interchange artifact.
