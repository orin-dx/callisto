## Summary

Two bugs fixed in `/Users/gabe/Projects/callisto/crates/callisto-graph/src/aggregate.rs`. No commits made.

### Bug 1 — Orphaned changeset silently consumed (line ~236)

**Root cause confirmed**: `agg.consumed.push(cs.path.clone())` was executed unconditionally before the entry loop. When every entry named a removed package, `resolve_target_package()` returned `Ok(None)`, the inner block was skipped, no severity was emitted, but the path was still in `consumed` — so `apply_version_plan()` would delete the file silently.

**Fix**: Moved the push to after the entry loop, guarded by a `matched_any` boolean. Also changed the `if let Some(...)` into a `match` to add the `None` arm, which emits a `DiagnosticCode::UnknownPackage` warning with the changeset path and package name.

### Bug 2 — Fixed/linked group crash on stale member (lines ~355, ~396)

**Root cause confirmed**: `union_fixed()` and `union_linked()` iterated all config-declared group member IDs without checking whether they still exist in the workspace. Stale members got inserted into `agg.severities`, which then fed into `solve_cascade`'s initial loop (`for (id, &amp;sev) in input.seed`), where `bump_target()` called `input.base.get(stale_id)` → `None` → `Err(GraphError::Manifest(MissingField))`.

**Fix**: Added `base_versions: &amp;BTreeMap&lt;PackageId, Version&gt;` parameter to both `union_fixed` and `union_linked`. In the propagation loop, before inserting into `agg.severities`, a `!base_versions.contains_key(&amp;m)` check skips stale members and emits a `DiagnosticCode::UnknownPackage` warning with the package ID and group name. Updated all three existing `union_linked` unit tests (now pass `base_versions`) and both call sites in `aggregate()`.
