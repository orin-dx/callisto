**4. Gotcha re: `#[serde(default, skip_serializing_if = "Option::is_none")]`:**
Any serde-Formatter-based canonicalizer (olpc-cjson included) only ever sees what `Serialize` emits — a field skipped via `skip_serializing_if` never reaches the formatter, so it's indistinguishable from a field that was never in the struct at all. That satisfies AC-001's "omitted field treated identically to a field that was never present" by construction. But it does **not** by itself guarantee "omitted == explicit null": if any `Option&lt;T&gt;` field were ever serialized as `Some(Value::Null)` rather than `None`, the formatter would emit `"field":null`, which is a different byte sequence than omission. This holds safely today only because callisto's `Option` fields are genuine `None`/`Some(T)` — no field is typed to allow an explicit-null variant. Worth a one-line implementation note (not a spec change): the guarantee depends on no future plan field being given a `Serialize` impl that can produce `Value::Null` from a `Some`.</result>
