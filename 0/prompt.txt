### Bug 1 — Python workspaces crash at graph load (Critical)

**Root cause confirmed**: `IdentityResolver::resolve` in `/Users/gabe/Projects/callisto/crates/callisto-graph/src/identity.rs` fell through to `_ =&gt; Err(GraphError::AmbiguousName { name: "unsupported ecosystem", ... })` for `Ecosystem::Pypi`.

**Fixes applied** (two complementary changes):

1. **`identity.rs` lines 74–106**: Added an `Ecosystem::Pypi` arm to `IdentityResolver::resolve()` that reads `pyproject.toml` and checks `[project].name` (PEP 621) then `[tool.poetry].name` (Poetry) — matching the same discovery logic already in `IgnoreWalkLocator`.

2. **`walk.rs` lines 55–63**: Replaced `identity_resolver.resolve(&amp;proj.path, proj.ecosystem)?` with `proj.id.clone()`. The locator already parsed each manifest during project discovery, so re-resolving was redundant and fragile. `IdentityResolver` remains public (used by `callisto-moon`) — only its call site in `walk.rs` was removed.

### Bug 2 — Cross-ecosystem cascade edges silently absent (High)

**Root cause confirmed**: `IdentityIndex::resolve_native` did `self.native.get(&amp;(eco, name))` — a strict same-ecosystem lookup. An npm package depending on a cargo crate by bare name got `resolve_native(Npm, "rust-addon")` which found nothing (the crate is indexed as `(Cargo, "rust-addon")`).

**Fixes applied**:

1. **`identity.rs` lines 175–242**: Rewrote `resolve_native` to try the exact `(eco, name)` lookup first, then fall back to scanning all other ecosystems for `name`. If exactly one cross-ecosystem match exists, it is returned. If multiple distinct `PackageId` values are found (genuine ambiguity), `None` is returned.

2. **`identity.rs` lines 243–272**: Added `resolve_native_with_fallback(eco, name, &amp;mut Vec&lt;Diagnostic&gt;)` — same logic but emits a `DiagnosticCode::UnknownPackage` warning when cross-ecosystem ambiguity is detected.

3. **`walk.rs` line 171**: Switched the edge-building loop from `resolve_native` to `resolve_native_with_fallback` so ambiguity diagnostics surface in the resolver's diagnostic list.
