5. Problem Solving:

**Changeset deletion idempotency design gap**: Documented that Callisto uses manifest versions (not git tags) as bump base, making "delete changeset after version" cause double-bump. Identified that the correct fix is to use last git tag as base, falling back to manifest only for new packages.

**Python workspace crash (Critical)**: `IdentityResolver::resolve` had no `Pypi` arm, returning `Err(GraphError::AmbiguousName { name: "unsupported ecosystem" })` for any Python project. Fixed by:
1. Adding Pypi arm to `IdentityResolver::resolve()`
2. Changing `walk.rs` to use `proj.id.clone()` directly (the locator already resolved the ID correctly)

**Cross-ecosystem cascade edges**: `resolve_native(eco, name)` used strict `(eco, name)` lookup. npm→cargo deps produced no graph edge. Fixed by adding `resolve_native_with_fallback` with cross-ecosystem lookup and ambiguity diagnostic.

**Fixed/linked group crash**: `union_fixed()` and `union_linked()` didn't check if group members still exist in workspace. Fixed by adding `!base_versions.contains_key(&m)` guard that emits warning diagnostic and skips stale members.

**Pre-release finalization bug**: `bump_target` always called `bump_prerelease()` when `pre` is `Some`, regardless of `PreMode::Exit`. Fixed by branching on `pre.mode` and calling `versioning.bump(base, sev)` for Exit mode.
