2. Key Technical Concepts:

- **Callisto**: Rust CLI + Moon WASM extension for polyglot monorepo versioning (10 crates)
- **PublishOrchestrator**: Generic `<R: RegistryClient, P: RateLimitPolicy, T: TimeProvider>` struct that iterates plan entries, calls `attempt_publish` per package, collects `PublishAttempt` outcomes
- **SubprocessRegistryClient**: Dispatches `RegistryClient` calls to cargo/npm/twine CLIs; requires `load_plan()` before `publish()` to thread per-package metadata
- **PublishPlan / PublishReport**: Distinct JSON artifacts; `PublishPlan` = what would be published (plan-publish), `PublishReport` = what was published (publish)
- **Report trait**: `const COMMAND: &'static str` + `schema_version()` + `diagnostics()`; implemented by `PublishPlan` ("plan-publish") and `PublishReport` ("publish")
- **DiagnosticCode**: Enum of machine-readable error codes emitted in plan diagnostics; new variants: `ChangesetReadError`, `GitDiscoveryFailed`
- **RegistryError**: `#[non_exhaustive]` enum with `RateLimited(Duration)`, `AuthFailed(String)`, `Network(String)`, `Other(String)`; new `kind_str()` method returns camelCase discriminator
- **PublishAttemptResult**: Tagged enum with `Published`, `AlreadyPublished`, `Failed { kind: String, error: String }`; `kind` carries camelCase RegistryError discriminator (`errorKind` in JSON)
- **PublishOptions**: Struct controlling plan-publish behavior; now has `only: Vec<String>` for package filtering
- **write_report_json**: New function in `output.rs` that wraps a `Report` value with a `"command"` discriminator field at serialization time
