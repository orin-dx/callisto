2. Key Technical Concepts:

- **Callisto**: Rust CLI + Moon WASM extension for polyglot monorepo versioning (10 crates)
- **PublishOrchestrator**: Generic `<R: RegistryClient, P: RateLimitPolicy, T: TimeProvider>` struct
- **SubprocessRegistryClient**: Dispatches `RegistryClient` calls to cargo/npm/twine CLIs
- **plan_publish / plan_version / apply_version_plan**: Core graph command functions
- **TagIndex**: Lazily-built, `OnceCell`-backed tag index; failure on first call leaves cell empty so second call retries (key to PUB-012 bug)
- **PublishTarget::Npm { registry, restricted }**: Model type for npm publish target — `restricted` field added in this session
- **NpmAccess::Restricted / Public**: Plan-level enum determining `--access` flag passed to npm CLI
- **`ws.tags()`**: `OnceCell`-backed lazy accessor; on failure, `OnceCell` remains unset and retries on next call
- **GitAccess**: Two-backend git accessor (gix primary, shell fallback) used by `ws.tags()` but NOT by `head_sha` (which uses gix-only `GitRepository::discover`)
- **TagTemplate / glob()**: Tag template struct; `glob()` produces `prefix*suffix`; `TagIndex::build` calls `version_grammar()` which can fail for mixed-ecosystem packages
- **ManifestRole::Canonical vs Platform**: Only Canonical manifests are counted in `version_grammar()`; a package with only Platform manifests has no canonical manifests and `version_grammar()` fails
- **`atomic_write`**: Canonical atomic file write with parent+grandparent fsync
- **RawConfig / ResolvedConfig**: Two-layer config system; `RawConfig` deserialized from TOML, `ResolvedConfig` built by `resolve.rs`
- **`#[serde(deny_unknown_fields)]`**: Missing from all `Raw*` config structs — silently drops typos
