## What was implemented

### New public API (`crates/callisto-changelog/src/write.rs`)

- `CombinedEntry` — carries `display_name`, `new_version`, and pre-rendered `summaries` for a single package in the combined changelog
- `write_combined_changelog(path, date, entries, permit)` — prepends a dated combined release section (H2 date → H3 `name@version` → bullet summaries) to the workspace-level changelog file; idempotent if the date heading already leads the file; atomically written via `callisto_manifests::atomic::atomic_write`
- Both exported from `callisto_changelog::lib.rs`

### New config (`crates/callisto-graph/src/config/`)

- `RawChangelogConfig` (`raw.rs`) — `combined`, `combined-path`, `combined-include-cascade` TOML fields
- `ChangelogConfig` (`resolve.rs`) — resolved struct with defaults (`combined = false`, `combined_path = "CHANGELOG.md"`, `combined_include_cascade = false`); added to `ResolvedConfig`

### Plan layer changes (`crates/callisto-graph/src/plan.rs`)

- `ChangelogWrite` gains `is_cascade_only: bool` — true when the bump had no real changeset (cascade/group/peer-escalation)
- `CombinedChangelogPlan` — new struct holding the absolute path, date string, and filtered entries
- `VersionPlan` gains `combined_changelog: Option&lt;CombinedChangelogPlan&gt;`

### `plan_version` (`crates/callisto-graph/src/commands/version.rs`)

- Marks `is_cascade_only` on each `ChangelogWrite`
- After building all writes, if `ws.config.changelog.combined`, generates the date via `chrono::Local::now()`, filters out cascade-only writes (unless `combined_include_cascade = true`), sorts packages alphabetically, and stores the plan
- Private helper `extract_combined_summaries` renders each `ChangeSource` variant to a human-readable string

### `apply_version_plan` (`crates/callisto-graph/src/apply.rs`)

- After per-package changelog writes, calls `write_combined_changelog` if `plan.combined_changelog` is `Some`, stages the resulting path via `git add`

### Dependency

- `chrono = { version = "0.4", features = ["clock"] }` added to workspace `Cargo.toml` and `callisto-graph/Cargo.toml`
