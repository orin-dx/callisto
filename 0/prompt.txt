  ## Design decisions
  1. **Cargo observation over the sparse index.** `http_get` runs `curl --silent --show-error --include --max-time 60 --request GET --url <url>` through the existing bounded `CommandRunner` (no `-L`, no credentials). Path layout `1/n`, `2/n`, `3/a/n`, `ab/cd/n`, lowercased. 404 or missing `vers` line → `Absent`; served + not yanked → `Exact` with `checksum` from `cksum` and `yanked: Some(false)`; served + yanked → `Conflict { RegistryVersionYanked }`; non-index body → `Indeterminate { MalformedResponse }`.
  2. **Protocol is typed, not guessed.** Added `RegistryProtocol { Http, CargoSparseIndex, CargoGitIndex }` to `PreparedRegistryBinding` (a sum type, not a bool). `canonical_registry_url` strips a leading `sparse+`; a *configured* cargo registry without that marker is a git index and fails closed as `Indeterminate { UnsupportedProtocol }`. The built-in `cratesIo` key is always sparse.
  3. **Built-in key override:** resolve.rs already lets `[registries.cratesIo] kind="cargo" url=…` overwrite the built-in entry, and `canonical_registry_url` already accepts `http`, so **no config change was needed** — documented in one line in the harness and in the semantic model.
  4. **One retry.** `policy::retry_observation(&dyn Sleeper, impl FnMut() -> Result<Attempt<T>, GraphError>)` with `Attempt::{Settled, Transient{value, retry_after}}`. 5 attempts, 2/4/8/16s, each wait clamped to 300s, `Retry-After` honoured and clamped. Used by registry HTTP, the GitHub release GET, and `git ls-remote`. No effect is retried. `Sleeper` is injected via `ProviderContext::with_sleeper` (`#[cfg(test)]`); production uses `ThreadSleeper`.
  5. **Post-publish confirmation** now uses the same observation with `Absent` mapped to transient (registry-lag semantics preserved). `poll_until_published` / `REGISTRY_CONFIRMATION_MAX_RETRIES` / `registry_confirmation_backoff` deleted; `require_registry_confirmation` and its `ReleaseIntentStale` regression test kept and still called.
  6. **PyPI** `can_observe_versions() → true`, `GET {endpoint}/pypi/{pep503-name}/{version}/json`; 404 Absent, yanked file Conflict, files present → Exact with `digests.sha256`; 200 with zero files → `RegistryVersionUnverified`. **npm** keeps `npm view`, now reports `checksum: None` honestly and returns a transient attempt on command failure.
