- **SubprocessRegistryClient**: Dispatches `RegistryClient` calls to cargo/npm/twine CLIs via `CommandRunner`; requires `load_plan()` before `publish()` to thread per-package metadata

- **--refresh-lockfiles**: `ApplyOptions::refresh_lockfiles` was a documented no-op (`_opts` unused); now implemented to run `cargo update --workspace` (for Cargo), `uv lock` (for Python/uv), or `poetry lock --no-update` (for Python/Poetry) after version bumps — prevents `cargo publish --locked` from failing on stale Cargo.lock

- **detect_rate_limit false positive**: Bare `text_lower.contains("429")` in `detect_rate_limit` matches cargo's own compressed-size output ("429.1KiB compressed"), causing infinite retry loops on unrelated failures. Fixed to require contextual phrases alongside "429".
