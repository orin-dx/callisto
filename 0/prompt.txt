- **PackageId::matches() semantics**: `Bare(x).matches(Bare(x))` → true; `Bare(x).matches(Prefixed(e,x))` → true; `Prefixed(e,x).matches(Bare(x))` → true; `Prefixed(e1,x).matches(Prefixed(e2,x))` → true IFF e1==e2. NOT changed by Track E.

- **ManifestDecl::ecosystem()**: Returns `Ecosystem` directly (not `Option<Ecosystem>`), delegating to `ManifestFormat::ecosystem()`.

- **escalated_by = None**: Means the new diagnostic is advisory under both `--strict` and `--strict-graph`, never escalating to a build failure.
