### Recommended fix shape

Centralize a single hermetic `init_repo(root: &amp;Path)` in `crates/callisto-fixtures/src/git.rs` that locally (not globally) configures, in order:

```rust
pub fn init_repo(root: &amp;Path) {
    run_git(root, &amp;["init", "-q", "-b", "main"]);
    run_git(root, &amp;["config", "user.email", "test@example.com"]);
    run_git(root, &amp;["config", "user.name", "Test"]);
    run_git(root, &amp;["config", "commit.gpgsign", "false"]);
    run_git(root, &amp;["config", "tag.gpgsign", "false"]);
    run_git(root, &amp;["config", "core.hooksPath", "/dev/null"]); // optional but cheap
}
```

This closes the commit-signing gap at the source for every caller and also fixes the `init.defaultBranch` ambient-config risk by pinning `-b main` (matching the precedent already set in `callisto-vcs/src/lib.rs:862-866`). Any remaining ad hoc `-c tag.gpgSign=false` on individual `git tag` invocations becomes redundant but harmless once the repo-local config is set — could be cleaned up opportunistically, not required for correctness.
