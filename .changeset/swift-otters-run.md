**The release PR shows each change exactly as the changelog will.** What's Changing lists every change as it will be written to `CHANGELOG.md`, grouped under collapsible Major, Minor and Patch blocks, and the Reason column names the changesets behind each bump, or counts them when there are more than three. In a prerelease, it also names an earlier changeset that set a higher bump, such as `major from pre/breaking`.
